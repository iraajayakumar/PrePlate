# Backend testing

The backend tests use H2 and do not require a running MySQL server. From the repository root, run:

```powershell
Push-Location backend
.\mvnw.cmd test
Pop-Location
```

For a package build without rerunning tests:

```powershell
Push-Location backend
.\mvnw.cmd -DskipTests package
Pop-Location
```

The test suite includes unit tests for authentication, meal schedule rules, forecasting calculations, waste metrics, and notifications. Spring Boot integration tests exercise authentication, student meal responses and preferences, admin access, forecasting/dashboard, notifications, consumption/waste analytics, and concurrent response handling.

The integration test profile uses an in-memory H2 database and a fixed clock (2026-11-14 13:40, Asia/Kolkata) so deadline behavior is deterministic. The runtime schema is not generated by Hibernate; tests provide their own H2 schema. Production/local runs should initialize MySQL using `database/schema.sql` and `database/seed.sql` before starting the application.
